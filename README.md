# Heat-wave-Analysis-and-its-impact-on-human-health
This was 2nd year mini project which was based on heat wave analysis,for that i made a PowerBi dashboard which shows the historial data of heat wave,mortality and how it impact.I tried to to power precaution and do's and dont's. A dedicated page for pregnant women offers tailored advice on diet, clothing, and first aid for heat-related issues.It also contain graphs of Mumbai UMIT college and Rahbhavan in Delhi which  which show the relation of humidity,heat index and temperaature by using python library(seaborne,pandas,matplot).
